# negiiinx.github.io

Personal website of Negin Ashrafi, live at https://negiiinx.github.io.

The site is one static page (`index.html`) with no build step. Edit it and push to `master`, and GitHub Pages publishes the change.

- `images/profile.jpg`: profile photo
- `images/logos/`: logos for the Education and Experience sections
- `publications/index.html`: redirects the old `/publications/` URL to the home page
